# AI Chat Platform — Project Journey

# Vision

The goal of this project is to build a modern AI-powered full stack chat platform inspired by applications like ChatGPT, Gemini, and Claude.

This project is not just about creating a UI clone.

The purpose is to learn:

* frontend engineering
* backend development
* APIs
* databases
* real-world software architecture
* AI integration
* deployment

while gradually transforming the project into a production-level full stack application.

---

# Current Stage

## Frontend Prototype

Currently, the project includes:

* Responsive AI chat UI
* Responsive sidebar
* Dynamic message system
* Enter-to-send functionality
* Auto scroll
* Mobile sidebar toggle
* Interactive frontend behavior

Built using:

* HTML
* Tailwind CSS
* JavaScript

At this stage, the project is frontend-only.

AI responses are currently simulated using JavaScript.
